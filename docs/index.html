🦊 Marble Rush Arena

Marble Rush Arena publishes short marble race videos: colorful marbles and country-flag marbles race down physics-simulated obstacle towers. Every race is a real physics simulation, so no two races are the same.

This site describes the publishing tool behind the Marble Rush Arena YouTube channel. The tool renders our own original animations and uploads them to our own channel using the YouTube Data API. It does not access any other user's data.
